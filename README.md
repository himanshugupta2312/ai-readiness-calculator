# AI Readiness Calculator

A small, client-side self-assessment prototype. Visitors answer six questions about their AI practices and receive an overall score plus suggested areas for development.

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

## How it works

- Responses are scored in the browser; there is no backend or account.
- The answers are not transmitted or saved by this page.
- The score reflects self-reported answers only. It is not a validated assessment, a measure of employee performance, or professional advice.

## Scope

This is a front-end prototype. It does not authenticate users, persist assessment results, or provide organization-wide reporting.
